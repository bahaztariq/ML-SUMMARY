1. Adjust Confusion Matrix Quadrants

Slide or type values to see how predictions vs actual reality shape every evaluation metric.

True Positive (TP) Actual Positive, Predicted Positive
False Positive (FP) Type I Error: False Alarm
False Negative (FN) Type II Error: Missed Hazard
True Negative (TN) Actual Negative, Predicted Negative
Accuracy 0%
Formula: (TP + TN) / Total
Precision (Exactness) 0%
Formula: TP / (TP + FP) — "When it predicts positive, how often is it right?"
Recall / Sensitivity (Completeness) 0%
Formula: TP / (TP + FN) — "Out of all actual positives, how many did we catch?"
F1-Score 0%
Harmonic Mean: 2 · (Precision · Recall) / (Precision + Recall)
Specificity (True Negative Rate) 0%
Formula: TN / (TN + FP)
